# Evidence checklist · Check before you share

Tick only checks you have actually completed. Leave unfinished items **To be checked**.

## Check the source

- [ ] Title, year and DOI match the published paper; preprint and published versions have not been mixed.
- [ ] Each important fact has a traceable section, table or other original location.
- [ ] If I read only the abstract or course card, the verification status says so.
- [ ] I did not invent a result count for a search I did not run, or describe fixed teaching selections as a systematic review.

## Check the study

- [ ] Clinicians, patients, cases and assessment counts have distinct units.
- [ ] I specified who uses AI, which resources the comparator can use and whether the model works alone.
- [ ] Written cases, simulated dialogue and real clinical care are distinguished.
- [ ] Scores, diagnostic accuracy and patient outcomes have not replaced one another.
- [ ] Percentages, percentage points, effect estimates and uncertainty retain their reported meanings.
- [ ] A nonsignificant difference is not described as proof of equivalence or absolutely no effect.

## Check the conclusion

- [ ] The conclusion answers my task question; indirect evidence is labelled.
- [ ] Model-alone performance has not been relabelled as a collaborative effect.
- [ ] Simulated assessment results have not been extended to established improvements in real patient outcomes.
- [ ] Unverified information remains **To be checked**; page numbers, quotations and references have not been invented.
