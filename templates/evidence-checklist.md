# 证据核查清单｜提交前，过一遍

中文 · [English](evidence-checklist.en.md) · [第 2 课](../lessons/02-evidence/README.md) · [首页](../README.md)

每个勾对应一次实际完成的检查。没查到的内容继续标“待核查”，下一次可以接着补。

## 1. 能找到来源吗？

- [ ] 题名、年份、DOI 与正式论文一致，没有混用预印本和正式版。
- [ ] 重要信息能回到具体小节、表格或其他原文位置。
- [ ] 只读摘要或课程卡片时，核查状态已如实标明。
- [ ] 检索命中数来自实际运行；固定教学选文没有写成系统综述。

## 2. 读清研究实际做了什么吗？

- [ ] 医生、患者、病例、评测次数的单位分清。
- [ ] 谁用 AI、对照能用什么、模型是否单独作答，已写清。
- [ ] 书面病例、模拟对话与真实临床场景分清。
- [ ] 评分、诊断准确性和患者结局没有相互替代。
- [ ] 百分数、百分点、效应量与不确定性保留原意。
- [ ] 未显著差异没有解释成“证明等效”或“绝对无效”。

## 3. 最后一句话，有没有越过证据？

- [ ] 结论回答自己的任务问题，间接证据已标明。
- [ ] 没有把模型单独表现写成人机协作效果。
- [ ] 没有把模拟评测写成已改善真实患者结局。
- [ ] 未核到的信息保留“待核查”，没有编造页码、引句或参考文献。

> 本课尤其复查 E2／E3／E6：场景、比较条件、患者获益。它们也是[建议通过规则](../lessons/02-evidence/answer-key.md)中的关键项。

保存初稿，再对照答案修订；让改过的判断也有记录。
