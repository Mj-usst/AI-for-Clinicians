# 证据核查清单

每个勾都应对应自己实际完成的检查；没有完成的项目继续保留待核查。

## 来源

- [ ] 题名、年份、DOI与正式论文相符；没有混用预印本和正式版。
- [ ] 每条重要信息有可回查的小节、表格或其他原文位置。
- [ ] 实际只读摘要或课程卡片时，核查状态如实标明。
- [ ] 未运行检索时没有填入虚构命中数；固定教学选文没有写成系统综述。

## 研究内容

- [ ] 医生、患者、病例、评测次数的单位分清。
- [ ] 谁使用 AI、对照能使用什么、模型是否单独作答写清。
- [ ] 书面病例、模拟对话与真实临床场景分清。
- [ ] 评分、诊断准确性和患者结局没有相互替代。
- [ ] 百分数、百分点、效应量和不确定性没有被改写。
- [ ] 未显著差异没有被解释为“证明等效”或“绝对无效”。

## 最后一句话

- [ ] 结论回答的是自己的任务问题；间接证据已标明。
- [ ] 没有把模型单独表现写成人机协作效果。
- [ ] 没有把模拟评测外推为已经改善真实患者结局。
- [ ] 未核到的信息保留“待核查”，没有编造页码、引句或参考文献。
